# Public research release

The release preserves every original experiment source file and all original plotting implementations. `source_inventory.json` lists their public paths and hashes. Additional entry points provide a portable launcher, result audit, paper build and small regression checks.

Portability changes:

- Dataset and output defaults are project-relative or supplied as arguments.
- Training and small fixtures accept an explicit device; optimizer mathematics, formal budgets, seed 42 and evaluation rules remain unchanged.
- A local mirror utility replaces the original machine-specific transfer procedure.
- Worker records use a neutral worker label rather than collecting the machine hostname.
- The historical scope amendment is inspect-only by default and requires an explicit flag to apply.
- Public records omit machine names, process identifiers and administrative connection details. Numerical evidence is retained.
- The Git history starts with this reviewed public tree; no development-machine history is imported.

The illustrated README explains the update for independent Lorentz-manifold groups. It is a conceptual PNG, not a measured plot. All actual paper plots are generated by the included Python code from the supplied data.

The quick-start fixture is intentionally not a registered experiment. Complete formal results are distinguished from deferred configurations and historical exploratory studies throughout the README, result records and paper.

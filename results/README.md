# Published result records

This folder contains the completed numerical evidence, including ties and unfavorable comparisons.

| Inventory | Count |
| :--- | ---: |
| Original registered configurations | 893 |
| Full-length completed configurations | 705 |
| Explicitly deferred configurations | 188 |
| Completed delayed-test task blocks | 6 |

- `revision/ID/result.json`: original numerical result, training configuration, endpoint and available selected-checkpoint measurements.
- `revision/ID/config.json`: the saved configuration.
- `revision/ID/deferred.json`: scope decision, separate from completion or numerical failure.
- `revision/_extension_selection/`: validation-selected tests after the complete 30-run search block.
- `historical/`: original exploratory summaries, kept separate from the revised benchmark.
- `../paper/evidence/completed_results.jsonl`: compact combined form of all 705 completed records.

The source records retain the original metric values. Machine-specific administrative fields are removed in this public release. Queue priority changed for 25 mechanism runs; it is a scheduling field, not a training or evaluation hyperparameter. The audit compares all other configuration fields exactly.

```bash
python scripts/summarize_results.py
```

Full per-step logs and model checkpoints are generated by the training scripts and are not included in Git. Exact data for all three published loss figures are included in `paper/figure_data/`. The manuscript appendix preserves the full comparison matrix and the explicit 705/188 execution scope.
